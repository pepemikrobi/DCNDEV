# DCNDEV v3.0 (Developing with Cisco Networks DevOps Style) Training Repository

## Topics:
- Labs based on Cisco Catalyst Center, Catalyst 9300 and 4320
- DevOps principles and practices
- Git, Python, Ansible and Terraform basics
- Introduction to GitLab
- Cisco Catalyst Center API
- Low-level API interaction with Cisco Catalyst Center: Postman, curl and Python
- Controller SDKs: Using Catalyst Center SDK 
- Using Ansible and Terraform with Cisco Catalyst Center
- Managing SD-Access fabric with Network-as-Code
- Catalyst 9300 application hosting
- Automated testing with pyATS
- Messaging automation: webhooks, Cisco Catalyst Center notifications, Webex bot, interacting with controllers with chat bot
- AIOps: Local and cloud LLMS, MCP servers for pyATS and Catalyst Center
- Working with CI/CD Pipelines
- Managing Cisco controller policies with GitLab CI pipelines
